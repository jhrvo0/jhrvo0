## Minha atuação no Grande Recife

Contribuo para o **RUMO**, plataforma de informação e planejamento de viagens no transporte público da Região Metropolitana do Recife.

No estágio, trabalho com interfaces web e mobile, evolução de APIs e integração de dados de linhas, itinerários, horários e paradas. Também atuo em mapas, planejamento de viagens, acessibilidade e validação dos dados apresentados aos passageiros.

Uso **Vue, TypeScript e Leaflet** nas interfaces, **Python/Django** nas APIs e **Capacitor** na versão mobile.
